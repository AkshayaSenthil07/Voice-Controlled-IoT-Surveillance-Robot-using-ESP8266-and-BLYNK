# Voice-Controlled-IoT-Surveillance-Robot-using-ESP8266-and-BLYNK
This project is a Wi-Fi enabled surveillance robot built using ESP8266,
L293D motor driver, and Blynk IoT platform.
The robot can be controlled remotely through a smartphone and supports
voice-assisted navigation for Forward, Backward, Left, Right and Stop
movements.
The system demonstrates IoT communication, embedded systems design,
wireless robot control, and real-time monitoring.

## Features
- Wi-Fi based robot control
- Blynk IoT integration
- Voice-assisted navigation
- Real-time remote operation
- Differential drive movement
- ESP8266 based architecture
- Mobile dashboard control

## Hardware Components
- ESP8266 NodeMCU
- L293D Motor Driver
- HC-05 Bluetooth Module
- DC Gear Motors
- Robot Chassis
- Li-ion Battery Pack
- Switch
- Jumper Wires
- Smartphone

## Software
- Arduino IDE
- Blynk IoT
- ESP8266 Board Package
- C/C++

## Working Principle
1. User sends command through Blynk or voice.
2. ESP8266 receives the command over Wi-Fi or using the bluetooth module.
3. Motor driver receives control signals.
4. Motors rotate according to the command.
5. Robot performs desired movement.
